# Refonte du site web Cocotte Équipement

## Je devais améliorer un site web au choix, dans le but de créer une meilleure expérience utilisateur, et améliorer l'esthétique.

### J'ai choisi ce site web : https://www.cocotte-equip.com/francais/items/fred-noir.html

### Ceci est la dernière phase du projet, elle consistait à intégrer une page web d'un prototype créé dans Figma des langages HTML, CSS et JS. La page web devait être accessible sur 3 médias de diffusion soit : mobile, tablette et grands écrans. Il a fallu intégrer des améliorations que nous avons identifiées suite aux rétroactions des tests-utilisateurs, des groupes cibles d’utilisateurs et de principales utilisations du site.
